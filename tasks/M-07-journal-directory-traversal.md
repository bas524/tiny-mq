# M-07 — обход каталогов журнала при ограниченных правах

Статус: реализовано и независимо проверено в рабочей ветке. Блокер [профиля C++](M-06-compact-runtime-provider-smoke.md).

## Spec ref

[SDD 72 / REQ-72-6](../docs/jms-spec/72-jakarta-delivery.md) и
[спецификация доставки](../openspec/specs/jakarta-session-delivery/spec.md).
Сохраняются атомарность восстановления, формат данных и границы хранилища.

## Symptom

В sandbox macOS чистая `main` собирается и проходит clang-tidy, но 137 тестов
падают на журнале с `Cannot open file`. Процесс может писать в каталог теста и
дойти до него по имени, однако открытие промежуточного каталога с `O_RDONLY`
требует права чтения его содержимого.

## Done criteria

- При наличии `O_SEARCH` промежуточные дескрипторы требуют только обхода.
  Конечный каталог остаётся читаемым, включая абсолютный путь с завершающим
  разделителем. На платформах без `O_SEARCH` сохраняется прежний режим.
- `O_NOFOLLOW`, `O_DIRECTORY`, `O_CLOEXEC`, обработка отсутствующих компонентов
  и границы записи журнала сохраняются.
- Штатные тесты доставки и восстановления проходят внутри действующего
  sandbox macOS, без расширения разрешений. Отдельный специалист проверяет
  изменённый обход и существующие негативные тесты хранилища.

## Scope-lock

`server/src/LocalTransactionJournal.cpp`, этот файл.

## Evidence

Команды, логи и вердикт проверки безопасности хранятся в
`handoffs/current/M-07/` в этой рабочей копии.

## Результат

На macOS в нативной песочнице прошли Debug, clang-tidy и ASan. В Debug и ASan
по 180 тестов. Проверка DeepSeek Flash через прямой профиль `deepseek`
вернула `approved` без замечаний. Она повторила сборку, clang-tidy и 22 теста
восстановления, доставки и устойчивости, а также проверила разбор пути с
завершающим разделителем. Вердикт относится к точному диффу продукта.

Шлюз производительности этой проверкой не закрыт. Для активации C++ профиля
отдельно остаётся сопоставимый замер по [M-05](M-05-local-nightly-performance.md).
