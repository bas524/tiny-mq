- **Статус:** исправление ASan принято в PR №13; продолжение Debug/дистрибутивов независимо проверено и прошло CI PR №12.

## Symptom

Два прогона ASan с одним `VCPKG_TAG` и манифестом получили одинаковый ключ
`vcpkg-Linux-asan-2026.06.24-9a87b356…`. На образе Ubuntu `20261111.196.1`
vcpkg восстановил 18 пакетов и задание заняло 2м26с. На образе `20261116.202.1`
он восстановил 0 пакетов и заново начал сборку зависимостей, включая protobuf.
GitHub сообщает `Cache restored successfully` в обоих прогонах.
[Прогон с 18 пакетами](https://github.com/bas524/tiny-mq/actions/runs/44291965795/job/134759156106) · [Прогон с 0 пакетами](https://github.com/bas524/tiny-mq/actions/runs/44307094002/job/134811345975)

## Spec ref

Инфраструктурная задача. Действующее задание ASan в
[`CI`](../.github/workflows/ci.yml) и команды проверок в [PROJECT.md](../PROJECT.md).

## Cause

Первичный ключ кэша не включает ревизию GitHub-hosted образа. При совпадении
ключа служба Actions восстанавливает уже существующий архив. Если его пакеты
не проходят проверку совместимости vcpkg на новой редакции образа, vcpkg их
пересобирает, а готовый архив по тому же ключу служба хранит без изменений.

## Done criteria

- Для разных редакций образа один манифест даёт разные первичные ключи ASan.
- Более ранний архив можно восстановить по префиксу, а совместимость пакетов
  проверяет vcpkg. После успешной сборки на новом образе доступен новый ключ.
- Синтаксис workflow и тест построения ключа проходят локально. Задание ASan
  выполняется на стандартном `ubuntu-latest` в GitHub Actions.

## Scope-lock

.github/workflows/ci.yml — ключи и получение редакции образа для кэша ASan, Debug и дистрибутивов. Команды компиляции, флаги, тесты и релиз не меняются. Постановка M-02.

## Продолжение: обычный CI и дистрибутивы

19.11 [Ubuntu job PR №12](https://github.com/bas524/tiny-mq/actions/runs/44475262476/job/135394150785)
на образе 20261116.88.1 получил точное совпадение старого ключа без редакции
образа, восстановил 0 пакетов, пересобирал зависимости около 19 минут и сообщил
Cache hit occurred on the primary key ... not saving cache. Причина та же,
что у ASan; её первоначальное исправление не охватило остальные два job.

Ключи Debug и дистрибутивов теперь учитывают runner.arch, ImageOS и
ImageVersion, сохраняя отдельное пространство ASan и восстановление по
совместимому префиксу. Дополнительный критерий закрытия: новая успешная сборка
сохраняет новый ключ, а следующий прогон на том же образе восстанавливает
совместимые пакеты. Проверки сборки и содержимого дистрибутива остаются прежними.

Свидетельство исходного сбоя:
handoffs/current/72/logs/github-ci-ubuntu-135394150785.log.
Локальная проверка расширения:
handoffs/current/M-02/logs/normal-ci-cache-followup.log.
