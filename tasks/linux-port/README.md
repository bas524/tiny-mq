# Задачи переносимости на Linux

Заведены 2026-08-01 после первого в истории проекта прогона тестов на Linux/x86_64
(GitHub Actions, ubuntu-latest). До переезда с GitFlic проект собирался и проверялся
только на macOS/arm64.

Результат первого прогона: **90 из 110 тестов прошли, 20 упали** — при полностью зелёном
macOS в том же прогоне.

## Наблюдение, которое стоит держать в голове

Ни один из этих дефектов не был внесён недавно: `PocoAnyVisitor.h` датирован 2022 годом.
Они существовали всё время и не проявлялись, потому что единственная платформа сборки
маскировала UB. Вторая платформа в CI окупилась на первом же прогоне — и продолжит
окупаться: она проверяет не «работает ли на Linux», а «опирается ли код на неопределённое
поведение».

Из этого следует практическое правило для новых спек: зелёный прогон на одной платформе
не является доказательством корректности работы с временем жизни объектов, порядком байт
и порядком инициализации.
