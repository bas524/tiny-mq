# Назначения Jakarta Messaging

Класс K2.

Локальные C++ клиенты могут читать очередь параллельно с разными селекторами,
получать независимые копии публикации по подпискам, просматривать очередь
и обмениваться ответами через временные назначения. Дельта фиксирует семь
принятых критериев, включая бюджет существующего пути с одним получателем.
Для назначений и подписок введена capability `jakarta-destinations`. Действующие
требования к соединению, конверту и повторной доставке описывают другие контракты.
