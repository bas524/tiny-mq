# Производительность SDD 71

REQ-71-7 сравнивает релизные сборки кандидата и чистого `main` из `7770feb`.
Порог роста медианы CPU time/op и коэффициента вариации (CV) составляет 5% для
каждого пути. Бенчмарк persistent-очереди учитывает процесс целиком, включая
worker хранилища. В исходном `main` получение оставляло запись в хранилище.
Кандидат помечает её удалённой до завершения receive. Единственное изменение
эталона для измерения — регистрация `MeasureProcessCPUTime`.

merge-кандидата. Привязку публичного запуска и коммитов к нынешним исходникам
проверил оператор: [журнал привязки](../../handoffs/current/71/logs/github-perf-source.log).
