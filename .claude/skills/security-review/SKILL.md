# security-review

Гейт контура Security Gate. Актуален с M3 (сетевой слой). Tiny-mq — тир T3, но приём внешнего трафика поднимает планку (spec-design: security review обязателен при работе с auth/вводом).

## Область
1. **AuthN/AuthZ (41):** SASL-PLAIN только поверх TLS; ACL на destination применяется на пути publish/subscribe (а не только в конфиге).
2. **TLS:** нет отключённой верификации по умолчанию; секреты (ключи/пароли) не в логах, коммитах, дефолт-конфигах.
3. **Сетевой ввод:** кодек STOMP/protobuf устойчив к некорректной длине кадра/усечению/переполнению; безопасная обработка границ.
4. **Flow control / DoS (42):** watermark'и + back-pressure не дают неограниченно расти буферам от злонамеренного клиента.
5. **Деструктивные admin-операции (43):** удаление очередей/подписок — за правом/подтверждением.

## Вердикт
```
status:   approved | rejected | N/A
evidence: <что проверено; для in-process — «N/A: изменение не касается сетевого слоя»>
```
- `rejected` — конкретная уязвимость + затронутый критерий; системное решение → требуй ADR.
- Не правь код сам — возвращай Producer'у.
