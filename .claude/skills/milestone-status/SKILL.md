# milestone-status

Контур «Знание» (Стандарт 8). Держит карту прогресса честной и подтверждённой свидетельствами, а не памятью.

## Предусловие

`done` ставится **только** при пакетах `approved` от агента-рецензента и всех шлюзов и `documented` от агента знания. Для принятия проверь `explained` и решение владельца.
Нет свидетельств — нет `done`.

**Стандарт 15:** свидетельства — существующие файлы прогонов по путям из пакетов, а не строка «тесты зелёные».
Открой их и убедись, что прогон был.

**Стандарт 20:** при расхождении между `*.json` агента и `handoffs/current/<spec>/chain.log` приоритет
у журнала: его пишет оснастка. Расхождение — отдельная находка.

## Процедура

0. **Перенос дельты в архив:** `python3 .claude/chain/openspec.py archive <NN>-<slug>` — 0 ошибок. Слияние в
   `openspec/specs/` идёт в тот же коммит закрытия. Нет изменения — садовник описывает поведение задним числом.
1. **`docs/jms-spec/README.md`:** строка задачи `drafted` → `done` с краткой пометкой, что реализовано
   и какой тест это подтверждает.
2. **`tasks/CONTINUE-HERE.md`:** следующий шаг по зависимостям.
3. Если решение меняло инвариант — ADR заведён (`adr-write`).
4. Долги, оставшиеся после задачи, заводятся задачами сопровождения в `tasks`, а не прозой.

## Формат пометки

`✅ done (что сделано; идентификатор ключевого теста)`.
