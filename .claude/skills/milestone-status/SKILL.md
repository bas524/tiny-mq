# milestone-status

Контур Knowledge (Standard 7, садовник). Держит карту прогресса честной и подтверждённой evidence, а не памятью.

## Предусловие
Обновляй статус на `done` **только** при наличии пакета от Reviewer со `status: approved` + зелёный `cpp-verify` (+ `perf-check` без регрессии, если тронут горячий путь). Нет evidence — нет «done».

## Процедура
1. **`tasks/UNIFIED-PLAN.md`:**
   - в таблице «Карта: спека → майлстон → статус» переведи строку спеки `⬜ planned` → `✅ done` с краткой пометкой, что именно реализовано (по образцу уже закрытых строк M0);
   - если это была последняя спека майлстона — обнови заголовок раздела майлстона (напр. «— ✅ ЗАКРЫТ»).
2. **`tasks/CONTINUE-HERE.md`:** укажи следующий шаг — какая спека идёт дальше по зависимостям/критическому пути `M0→M1→…→M6`.
3. Если решение меняло инвариант — убедись, что `knowledge-gardener` завёл ADR (`adr-write`), и сошлись на него.

## Формат пометки
Кратко и проверяемо: `✅ done (что сделано; имя ключевого теста)`. Пример из M0: `✅ done (SendOptions: send(msg,opts)/setDefault; SendOptionsTest)`.
