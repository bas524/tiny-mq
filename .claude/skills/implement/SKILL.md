# implement

При partial исполняй только allowed из записи допуска. Передавай тот же набор requirement_ids,
не расширяй файлы и остановись при зависимости от любого blocked-вопроса. Полный Test plan не расширяет
этот допуск. Правила — [HANDOFF.md, «Ограниченный допуск»](../../chain/HANDOFF.md).

Порядок работы агента-автора (AEF, Стандарт 2 о SDD и Стандарт 3 об исполняемых критериях). SDD — контракт:
делаем ровно то, что в ней зафиксировано.

## Шаги

0. **Объявить `target_files`** (целевой набор, Стандарт 18) — набор файлов, которые ты будешь менять.
   Маршрутизатор сверяет его с рабочим деревом и **останавливает цепочку** при выходе за набор.

1. **Прочитать SDD.** `docs/jms-spec/<NN>-*.md`: `Acceptance Criteria`, `Persistence / wire implications`,
   `Dependencies`, `Stop-conditions`, `Entity inventory`, `Open questions` и **`Test plan`**.
   Зависимости из `Dependencies` закрыты в `docs/jms-spec/README.md`? Если нет, остановись и сообщи оркестратору.

2. **Критерии приёмки → тесты.** Каждый сценарий = отдельный тест в `tests` с идентификатором
   из строки `Test:` (`Suite.Case`). Это полный и единственный объём «сделано».

3. **Унаследованные ограничения продукта с историей.** Явно перечисли, что наследуется без изменений:
   <!-- project-start -->
   см. INHERITED_CONSTRAINTS в PROJECT.md
   <!-- project-end -->
   Отклонение — только через ADR (`adr-write`), не тихим выбором.

4. **Реализация.** Минимально достаточный код под критерии. Инварианты:
   <!-- project-start -->
   - парные изменения: `кодер ↔ декодер; заголовки ↔ кешированные байты ADR-0008; MessageProperty ↔ PocoAnyVisitor; Destination::save ↔ Destination::deliverCommitted`;
   - горячие пути `Destination.*, DeliveryScheduler.*, Producer.*, Consumer.*, Session.*, Message.*, MessageProperty.*, Selector.*, LinearStorage.*, ConcurrentLinearStorage.*, TransactionBuffer.*; сетевой data plane после появления` → готовься к `nfr-gate`, нет замера производительности — добавь;
   - повторявшиеся дефекты: `исключения из деструктора (ADR-0006); регрессия кешированных заголовков (ADR-0008)`.
   <!-- project-end -->

5. **Проверка.** Навык **`verify`**: сборка и все тесты. Затем, если тронут горячий путь, навык **`nfr-gate`**.

6. **Пакет передачи** (AEF, Том IV, §5.2):
   ```
   artifact:         <дифф + новые тесты>
   evidence:         ["handoffs/current/<NN>/logs/verify.log", "handoffs/current/<NN>/logs/bench-*.log"]
   evidence_summary: <строка для человека; доказательной силы не имеет>
   status:           produced
   target_files:     [<объявленный на шаге 0 набор>]
   provenance:       model=<producer-model> role=Producer autonomy=R2
   sdd_ref:          docs/jms-spec/<NN>-<slug>.md
   ```

## Остановка вместо умолчания (Стандарт 2)

Пункт `Stop-conditions` или неоднозначность, которой там нет, → `status: paused` и вопрос к `Owner`
в поле `question` (с кем консультироваться, подскажет маршрутизатор). Это **не отказ**: работа возобновляема.
Запрещено: выбрать «наиболее вероятное», реализовать оба варианта, отложить в `// TODO`.
